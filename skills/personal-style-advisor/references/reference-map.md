## 已确认的运行模块

- `hair-guide`：可见特征与限制、推荐/较低优先级、短中长发、刘海/分缝和发色。
- `tops-styling`：颜色/领型/面料与独立 look 建议。report-04/05 延用六页拆分。
- `neckline-hair`：按当前选择的服装类别和目标场景，选用稳定 ID 目录中的八项；每行三个针对同一人的发型与一至两句理由。三类之间可以共享 ID，扩展礼服款只由用户或场景选择。

本文件是来源说明，不包含参考截图、人脸素材或外部图片文件。中英简短标签可以使用；除非用户要求，不额外加泰语。
