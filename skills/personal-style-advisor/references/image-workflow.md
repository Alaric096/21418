# 图像制作流程

## 准备

1. 核实本次可读的本人照片、目标页、用户类别选择、领口清单、场景、排除项和允许变化项。
2. 建立本次运行副本：`analysis.md`、`copy-deck.md`、`style-profile.json`、`report-contract.json`、`qa.md`。冻结图片内应出现的短文案和标签。
3. 按 `identity-and-pose.md` 记录每张照片的职责与可观察限制。
4. 先生成少量样片（如近景发型与动态穿搭），检查人脸/眼镜/体态以及造型方向。样片通过后再扩展页面；若样片显示实质漂移，先调整提示再生成整页。样片不要求用户逐页审批，除非用户主动提出。

## 生成

使用当前会话实际可用的图像工具，按其公开能力传递原始参考图并保存真实返回结果。每次调用尽量引用原始照片；合格样片仅可辅助版式或风格，不可成为唯一人物锚点。若工具不支持多张参考图，选择最适合当前页面职责的清晰原图，明确记下未能使用的辅助锚点。

保持原照中可见的脸、眼镜、标记、肤色纹理和体态；只改变任务指定的发型、发色、衣服或场景。不要承诺编辑只影响指定区域；生成后仍检查其他可见区域。

## report-06 总览和细节

总览结构为 8 行、5 个视觉列：领口示意 + 三个人像 + 中文理由，共 24 名人像。使用本次固定的 8 个领口 ID 和顺序；每行三发型确有区别，人像穿着该行领口，并显示肩颈和完整领口边缘。

先制作一行三人像小样，按最终总览列宽试排，再决定完整页面。如果 8 行总览按最终交付尺寸无法辨认发型或领口，仍可留作导航总览，但必须增加放大详情页，例如分两页各展示四行。详情页每格仍引用原始照片并逐格检查，不能用看不清的总览代替验收。

不假定工具会自动拼接、修图或精确复用人物。若当前工具不能生成/合成可读的全套页面，停止并记录具体阻塞；不删行、不藏格、不用脚本合成人脸图来宣称通过。

## 保存和停止

把最终图保存到本次结果目录 `reports/`。复核实际返回文件：存在、能打开、符合页面规格。逐页最多两次有具体依据的修订；仍有明显人物漂移、错领口、漏项或不可读时停止该页，准确标为 `needs_revision` 或 `blocked`。中间图、参考图、未通过图与文案不计合格成品。
