# Personal Style Advisor v5

此版本沿用 v4 的类别分流、稳定领口 ID、人物一致性 QA 与自选风格组数量，并加入逐套个性化穿搭决策。先读照片中可见的发型、眼镜、肩颈和已有服装轮廓，再结合用户场景与偏好，为每套记录依据、造型选择、预期效果、备选和实际试穿点。

照片看不到的腿长、真实尺码、色彩季型或性格不作为“量身定制”依据。若用户明确指定韩系、日系、美式街头、慵懒休闲和偏商务各四套，按五组共二十套制作；不把这个示例变成所有任务的默认数量。

## report-05 配置与 QA

style-profile.json 的 outfit_plan.groups 记录组名、数量、look IDs、输出页、风格说明和逐套决策；实际总套数等于各组数量之和。总数与逐组数量冲突时默认先确认；明确要求继续时按逐组数量执行并记录口径。QA 对每个 look 单独检查身份、眼镜、自然肤质、可见体态、衣服层次、领口、动作和组间差异。

逐套依据和设计决策填写在运行副本的 style-profile.json、analysis.md 与 copy-deck.md；规则见 [个性化穿搭决策](references/personalized-outfits.md)。图像 QA 同时检查实际衣服是否落实文字方案，不能用换背景充当个性化。

四套一页时至少三种不同可见动作。风格组需要在单品和层次上真实有别；宽松衣服不代表人物身体被拉宽。

## 六页报告路由

| ID | 页面 | 主要内容 |
|---|---|---|
| report-01 | 个人基础与风格概览 | 可见观察、成像限制和目标方向 |
| report-02 | 发型推荐及长短对比 | 推荐/较低优先级；短、中、长发 |
| report-03 | 刘海、分缝与发色 | 刘海/分缝、色块与模拟 |
| report-04 | 上衣颜色、领型与面料 | 稳定目录中的五个领型、颜色和面料 |
| report-05 | 用户指定风格组穿搭 | 一组或多组；按各组指定数量生成 |
| report-06 | 领口 × 发型适配表 | 8行×5视觉列×24个人像；必要时增加详情 |

报告仍有六个核心 report_id；report-05 可展开成任意数量子页，report-06 详情页用于补充可读性。

## 运行与隐私

制作前实际查看本人照片。每张生成图引用当前任务可读的原始照片并记录职责和允许变化。保持脸部关系、眼镜、可见标记、自然肤质和本人可见体态。每页和每格记录 pass、needs_revision、not_tested 或 blocked。原图和个人报告不放入 Skill ZIP。

图像试穿是造型模拟，不保证真实尺码、材质或线下效果；不得声称绝对身份一致、医学判断、固定肤色季型或精确身材比例。此 ZIP 只交付技能文件，不会自动安装。
