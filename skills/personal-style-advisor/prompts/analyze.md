# 个人照片分析提示词

按用户本轮要求、本人照片与造型目标进行可见观察。开始前读取 `references/visual-safety.md`、`references/identity-and-pose.md` 和本次实际需要的参考。参考示例人物不能替代用户本人。

## 确认选择与照片

1. 先记录用户已明确的穿搭类别、目标场景、明确排除项与眼镜偏好。优先顺序为用户选择/排除项与目标场景 > 照片当前穿衣线索。
2. 用户没有指定类别时，只能把照片服装作为可改选线索；不得据此判定性别身份。若类别会改变版型/领口而仍不明确，只问男装、女装或中性一次。不得因短发/长发、脸部特征或单件衣物替用户分类。
3. 逐张确认照片可读，并给每张照片分配职责：主脸部参考、侧前方轮廓参考、半身/全身可见体态参考。若左右镜像未确认，按画面位置记录。
4. 观察脸部外轮廓、眉眼鼻唇关系、眼镜、可见标记、发丝/发际线与可见肩颈；区分清楚可见、部分可见、无法判断。说明光源、滤镜、遮挡、角度或裁切如何限制判断。

## 提出建议

根据用户目标提出发型、分缝、刘海、发色、颜色、面料和本类别领口建议。每项都写明可见依据或用户偏好条件；区分“推荐”“可尝试”“较低优先级”。不推断精确身材比例、固定肤色季型、性格、年龄或健康。

如制作图像，先确定每张图片本次允许变化的内容，其他稳定外观作为保护项；填入本次运行副本 `style-profile.json`、`analysis.md` 与 `copy-deck.md`。视觉试穿只是模拟，不代表现实效果。

制作 report-05 时再读取 `references/personalized-outfits.md`。把可见线索、用户偏好、目标场景和不确定性写成穿搭决策记录；对脸部外观仅描述与造型有关的可见关系，不从“五官”推断人格、年龄、身份或客观美丑。“气质”只可作为用户自述的风格目标，或明确标为照片中呈现的视觉印象且受表情、服装、光线影响。照片未展示腿脚时不得据此判断腿长或鞋型适配。
