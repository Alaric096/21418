# 报告模式与生成路由

读取 references/report-contract.md，按用户要求选择独立模块或报告页面。复制 templates 到本次运行目录并填写副本，不修改技能模板。

1. 用户点名模块或部分页面时，只运行对应模块或 report_id。
2. 记录当前服装类别、场景、排除项、照片职责和稳定领口 ID。
3. report-05 按用户指定的风格组和套数分配唯一 look_id。先依 personalized-outfits.md 建立证据到穿搭决策的映射，再逐套记录搭配、领口、动作、场景、个性化理由与待试穿点。数量冲突按 report-contract.md 处理并留痕。
4. 冻结短文案和格子顺序到 copy-deck.md。图片工具若不能可靠写中文，文字需另验或明确标未验。
5. 每张真人图都引用原始本人照片，明确身份/肤质保护项和本图允许变化。旧生成图不能做唯一人物锚点。
6. 按图像流程、人物姿态规则生成，再按逐页逐格复核提示词验收。
7. 只计实际存在且逐项通过的图片；未生成或素材不可读的页面标 blocked 或 not_tested。

页面路由：01 总览；02 发型长短；03 刘海/分缝/发色；04 颜色、领型与面料；05 一个或多个用户指定风格组且数量自选；06 全部已选领口与24个人像格，必要时总览加详情。
