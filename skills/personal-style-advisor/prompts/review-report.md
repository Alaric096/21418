# 逐页与逐格复核

把实际生成文件对照本次契约、文案、style profile 和当前可读原始本人照片复核。复核作品而非提示词；记录可见证据与限制。

## 通用检查

文件存在且能打开；数量、顺序、文字、标签与版式完整；逐人检查脸部关系、眼镜/可见标记、自然肤质、可见体态和跨图连续性。核对变化是否限于指定发型、领口、穿搭、动作和场景。使用 pass、needs_revision、not_tested 或 blocked，并说明不可观察项。身份一致性是人工可见比较，不给百分比。

## report-04 与 report-05

04 核对稳定领口 ID、文字和本人实穿。

05 每组套数必须等于指定数量；逐套核对唯一 look_id、衣服层次、场景、动作、领口、人物连续性与身体轮廓。再把每套与 analysis.md 和 copy-deck.md 对照，检查依据有来源、服装落实预期视觉效果、未知项没有写成事实、备选和现实试穿点明确。组间要看出单品和层次上的风格差异，不能只换背景/颜色。四套页至少三种不同且可见的自然动作。缺套、明显重复、错误服装类别、人物被拉宽、手部遮脸或动作被遮挡时，不得标通过。

## report-06

数清8行、5个视觉列、24个人像，核对每人领口和本行一致、三种发型有区别。按最终尺寸检查脸、发型和完整领口。总览无法辨认时增加覆盖全部行的详情并逐格复核；总览看不清的格不算通过。

最多两次有明确原因的修订。仍未通过时准确记录缺口。示例、草稿和 QA 文本不计图片成品。
