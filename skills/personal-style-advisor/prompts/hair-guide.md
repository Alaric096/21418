# HAIR GUIDE：综合发型分析

用于独立 `hair-guide` 模块，或六页 `report-01`、`report-02`、`report-03`。先运行 [照片分析提示词](analyze.md)，再按对应报告 ID 编排内容；同时按 [人物参考与变化边界](../references/identity-and-pose.md)保护脸部、眼镜和可见标记。观察和建议必须来自可读的本人照片，绝不能把参考截图模特当作用户。

## 观察与建议

按可见程度记录脸部轮廓/下颌、发丝纹理、视觉发量、发际线/额头和用户当前风格；不可见项标“无法判断/未观察”。基于观察和用户目标分别整理推荐与较不推荐方向，避免精确比例和固定季型结论。

- **report-01 个人基础与风格概览**：只用 ref-05、ref-07、ref-08 的分析部分；概括可见观察、成像限制及与目标有关的风格方向。ref-05 只作轮廓/肩颈等观察线索，不抄领口适配答案。
- **report-02 发型推荐及长短对比**：分别呈现推荐/较不推荐，并给短发、中发、长发三档同本人对比；本页不重复 report-03 的发色内容。
- **report-03 刘海、分缝与发色**：分析分缝和刘海选项，以冷/暖/中性发色色块及本人试色作比较；本页不重复 report-02 的长短对比。
- **独立 hair-guide**：在一份整体报告中包含上述观察、推荐/较不推荐、短中长、分缝/刘海和发色色块/本人试色。

## 版式和图像

整体布局参照主肖像、上方分析卡、中部比较网格、侧边长度栏、底部发色与可选总结的关系。画面视觉主导、标签简短，保留本人特征与真实发丝质感；避免网红脸、塑料皮、过度磨皮和夸张 AI 卷发。发色测试视作造型模拟。

独立模块用 `module_id: hair-guide`；六页执行时分别标记 report ID。所有个性化图像以同一原始本人照片为参考，并逐张复核。
