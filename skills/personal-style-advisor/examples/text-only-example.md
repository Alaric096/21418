# 虚构流程示例：模块内容已确认，图像工具不可用

本例演示文字降级，不含用户照片或生成图片。

**用户请求：**“我想单独做上衣搭配模块，但当前会话不能生成图。”

**处理：**直接运行 `tops-styling`，不要求完成六页套餐。若用户给了可读本人照片，可以整理观察、颜色/领型/面料建议和 4–5 套 look 文案；如没有照片，只给不针对个人的通用结构，避免个性化结论。图像工具不可用时，交付文案及清晰的阻塞说明。

**记录：**`module_id: tops-styling`；模块图片状态 `blocked` 或 `not_tested`；无实际图片路径，模块图片通过数为 0。单模块文字不计入六页成品数量。
