# 虚构流程示例：独立模块与六页组合

本例仅说明路由，不含本人照片或图像成品。

**独立模块请求：**“只做领口与发型适配表，按中性日常穿搭。”处理时将 `gender-neutral` 记为服装目录，按目录读取 8 个稳定领口 ID；图中不暗示用户的性别身份。该模块单独记录 `module_id: neckline-hair`，不自动算作六页中的 report-06。

**六页请求：**“请按已批准拆分页制作第 2、3、6 页，按男装，眼镜保留。”处理时直接路由到 report-02/03/06，将眼镜框记作稳定外观，把本次男装目录 ID 写入 `style-profile.json`；不重复询问已确认的页序。

report-06 总览含 8 行、5 个视觉列和 24 名人像。按最终尺寸检查小格；无法辨认时保留总览并增加覆盖全部行的详情页，详情逐格 QA。无可读本人照时不生成个人图，所有图片状态保留为 `not_tested`。
